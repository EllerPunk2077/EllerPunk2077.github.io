Was die Anwendung macht

ClipCashFarm ist ein privates Werkzeug, das öffentlich verfügbare Twitch-Clips im Hochformat aufbereitet und auf den eigenen YouTube-Kanal des Betreibers hochlädt. Die Anwendung wird nur vom Betreiber selbst genutzt.

Welche Daten verwendet werden

  • Google/YouTube: Die Anwendung nutzt die YouTube Data API mit der Berechtigung youtube.upload, um Videos auf den Kanal des Betreibers hochzuladen. Der dafür nötige Zugangsschlüssel (OAuth-Token) wird ausschließlich lokal auf dem Rechner des Betreibers gespeichert.
  • Twitch: Die Anwendung ruft über die Twitch-API öffentlich verfügbare Informationen zu Streams und Clips ab (z. B. Titel, Aufrufzahlen).

Weitergabe und Speicherung

Es werden keine personenbezogenen Daten Dritter gesammelt, verkauft oder an Dritte weitergegeben. Es gibt keine Server-Datenbank; alle Daten bleiben lokal beim Betreiber.

Nutzung der YouTube API Services

Diese Anwendung nutzt die YouTube API Services. Es gelten die YouTube-Nutzungsbedingungen und die Google-Datenschutzerklärung. Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
